## 项目经历

### 中国城市生活成本与幸福感分析可视化平台 ｜ 个人项目 ｜ 2026.06.10 – 至今

**技术栈：** Python · Streamlit · pandas · NumPy · scikit-learn · Matplotlib · Seaborn · pyecharts · requests · BeautifulSoup4 · DeepSeek API · pytest · Docker · GitHub Actions

**项目概述：** 独立完成从数据生成/采集、清洗建模、可视化分析到 AI 解读与云端部署的全链路数据产品。覆盖全国 **248 个城市**、**6 张截面数据表（1,488 条城市指标）+ 4,960 行房价历史 + 792 条支柱产业记录**，提供 10+ 个分析模块与 13 类图表。

**主要工作：**

- **数据工程**：设计多源 CSV 加载与合并流程，按 `city` 左连接生成宽表，派生「住房可负担指数（年收入÷房价）」「综合宜居评分（0–100）」等指标；编写数据质量校验与字段健康检查；以「文件 mtime + size」构造缓存签名，数据文件变更后 Streamlit 缓存自动失效。
- **机器学习建模**：构建 **13 维面板特征**（滞后 1/3/5 年涨幅、长期 CAGR、涨幅波动率、房价收入比、收入/人口基本面等），以下一年房价对数涨幅相对全国动量的偏离为目标，训练 `GradientBoostingRegressor`（200 棵树、depth=3、subsample=0.85）；采用 **expanding walk-forward 滚动验证**，严格避免前瞻偏差，输出 RMSE / MAE / R² / 方向命中率；对选定城市做**递归多步预测**，基于验证残差标准差给出置信区间与特征重要性；scikit-learn 缺失时自动降级为 NumPy 岭回归，保证功能可用。
- **可视化体系**：基于 Matplotlib（Agg 后端）/ Seaborn 封装 **13 类图表工厂**（散点+回归线、相关性热力图、分布直方图、排名条形图、可负担性分布、城市对比、城市百分位画像、异常值标注、房价预测/回测、五维得分、薪资×需求散点、技能热度图等），实现透明玻璃风格与统一视觉规范；通过 `font_manager` 注册内置 OFL 中文字体，解决 Linux 云端图表中文「方框」缺字；用 pyecharts 生成省级宜居度地图与 Top50 城市价值指数地图。
- **爬虫与数据采集**：实现通用爬虫框架——自定义 UA 标识、`robots.txt` 准入校验（按主机缓存解析结果）、同域 1s 最小间隔限速、失败指数退避重试、按 URL 摘要落盘缓存、支持 `http(s)://` 与 `file://` 双协议；`requests → urllib`、`BeautifulSoup → html.parser` 双级依赖降级；解析与清洗分离，数值兼容千分位/百分号/「—」等脏数据，稳定产出 **792 条**支柱产业记录作为就业推荐数据源；默认使用离线快照，保证 CI 与无网络环境可复现。
- **推荐算法设计**：设计可解释的**五维加权打分模型**（技能匹配 30% / 薪资 25% / 发展空间 20% / 岗位规模 10% / 生活宜居 15%，并按学历门槛以 `0.94^档差` 折减），全部向量化实现并保留标量参考版本做逐元素等价性校验；输出技能缺口、典型岗位与逐条提升建议；前端滑块实时调整权重，画像哈希作为缓存键避免重复计算。
- **LLM 应用落地**：采用「**本地检索计算 + 大模型生成**」两段式架构：城市指标、百分位、全国/本省参照、90㎡ 月供与替代城市全部本地确定性计算，仅将压缩后的事实（硬上限 2,800 字符）送入 DeepSeek；通过固定系统提示词命中前缀缓存、单轮对话、`max_tokens` 上限、会话级结果缓存（≤8 条）、提示词注入防护与密钥脱敏，在保证结论可溯源的同时显著降低调用成本；对 401/402/429/5xx/超时等错误做可行动提示。
- **工程质量保障**：业务逻辑抽离为 15 个职责单一的独立模块，纯函数与 Streamlit UI 解耦，便于复用与测试；使用类型注解、dataclass、`RotatingFileHandler` 滚动日志、环境变量配置与依赖降级；编写 **150+ 个 pytest 用例**（覆盖数据加载、分析、预测、图表、爬虫、推荐、API 配置、字体，并用 monkeypatch 模拟网络层、Streamlit AppTest 做无头端到端测试）；GitHub Actions 在 push/PR 自动安装依赖、运行测试并上传覆盖率报告。
- **部署与疑难排查**：编写 Dockerfile 多阶段分层构建（依赖层缓存）并配置 `/_stcore/health` 健康检查；定位 Streamlit Cloud「文字正常但所有图表空白」问题，追查到 starlette 1.9 的 gzip 中间件吞掉 `http.response.start` 导致 `/media/` PNG 返回 500，通过锁定 `starlette==1.3.1` 并补充 ASGI 响应顺序回归测试彻底修复。

**项目成果：** 形成可复现、可测试、可部署的完整数据应用；数据管道一条命令重建，测试全绿并接入持续集成；把「数据清洗 → 统计分析 → 机器学习预测 → 可解释推荐 → 大模型解读」串联为可演示的端到端产品。
