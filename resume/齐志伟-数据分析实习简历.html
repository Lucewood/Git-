项目经历

中国城市生活成本与幸福感分析可视化平台（个人项目）

2026.06.10 – 至今
技术栈：Python · Streamlit · pandas · NumPy · scikit-learn · Matplotlib · Seaborn · pyecharts · requests · BeautifulSoup4 · DeepSeek API · pytest · Docker · GitHub Actions

项目概述：独立完成从数据生成 / 采集、清洗建模、可视化分析到 AI 解读与云端部署的全链路数据产品。覆盖全国 248 个城市、6 张截面表（1,488 条指标）+ 4,960 行房价历史 + 792 条支柱产业记录，提供 10+ 个分析模块与 13 类图表。

  • 数据工程：设计多源 CSV 加载合并流程，按 city 左连接生成宽表，派生「住房可负担指数（年收入 ÷ 房价）」「综合宜居评分（0–100）」；编写数据质量校验与字段健康检查；以「文件 mtime + size」构造缓存签名，数据变更后 Streamlit 缓存自动失效。
  • 机器学习建模：构建 13 维面板特征（滞后 1/3/5 年涨幅、长期 CAGR、涨幅波动率、房价收入比、收入 / 人口基本面等），以下一年房价对数涨幅相对全国动量的偏离为目标，训练 GradientBoostingRegressor（200 棵树、depth=3、subsample=0.85）；采用 expanding walk-forward 滚动验证严格避免前瞻偏差，输出 RMSE / MAE / R² / 方向命中率；对选定城市做递归多步预测，基于验证残差标准差给出置信区间与特征重要性；sklearn 缺失时自动降级为 NumPy 岭回归。
  • 可视化体系：基于 Matplotlib（Agg 后端）/ Seaborn 封装 13 类图表工厂（散点 + 回归线、相关性热力图、分布直方图、排名条形图、可负担性分布、城市对比、城市百分位画像、异常值标注、房价预测 / 回测、五维得分、薪资 × 需求散点、技能热度图等），统一透明玻璃风格；通过 font_manager 注册内置 OFL 中文字体，解决 Linux 云端图表中文「方框」缺字；用 pyecharts 生成省级宜居度地图与 Top50 城市价值指数地图。
  • 爬虫与数据采集：实现通用爬虫框架——自定义 UA 标识、robots.txt 准入校验（按主机缓存解析结果）、同域 1s 限速、失败指数退避重试、按 URL 摘要落盘缓存、支持 http(s):// 与 file:// 双协议；requests → urllib、BeautifulSoup → html.parser 双级依赖降级；解析与清洗分离，数值兼容千分位 / 百分号 / 「—」等脏数据，稳定产出 792 条支柱产业记录；默认离线快照保证 CI 无网络可复现。
  • 推荐算法设计：设计可解释的五维加权打分模型（技能匹配 30% / 薪资 25% / 发展空间 20% / 岗位规模 10% / 生活宜居 15%，学历门槛按 0.94^档差 折减），全部向量化并保留标量参考版本做逐元素等价性校验；输出技能缺口、典型岗位与逐条提升建议；前端滑块实时调参，画像哈希作为缓存键避免重复计算。
  • LLM 应用落地：采用「本地检索计算 + 大模型生成」两段式架构：城市指标、百分位、全国 / 本省参照、90㎡ 月供与替代城市全部本地确定性计算，仅将压缩事实（硬上限 2,800 字符）送入 DeepSeek；通过固定系统提示词命中前缀缓存、单轮对话、max_tokens 上限、会话级结果缓存（≤8 条）、提示词注入防护与密钥脱敏，在结论可溯源的同时降低调用成本；对 401 / 402 / 429 / 5xx / 超时等错误给出可行动提示。
